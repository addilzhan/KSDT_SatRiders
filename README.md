## 🤖 Концепция Машинного Обучения

### Почему мы выбрали **Ансамблевое обучение**? 🤔

Мы выбрали ансамблевое обучение из-за его высокой точности и устойчивости.  
Ансамблевое обучение — это метод машинного обучения, при котором комбинируются несколько моделей (например, регрессионные модели, нейронные сети) для получения более точных прогнозов. Объединение моделей позволяет сократить ошибки и повысить точность.

## 🧠 Как работает наша модель

Наша модель машинного обучения анализирует спутниковые данные и предсказывает экологические факторы, такие как уровень загрязнения воздуха, ветровые паттерны и топографию. Алгоритм включает:

1. **Сбор данных**: Сбор данных с различных датчиков — концентрации газов, скорость и направление ветра, температура, влажность и др.
2. **Предобработка данных**: Очистка, нормализация и подготовка данных.
3. **Ансамблевая модель**: Используется комбинация моделей (Random Forest, Gradient Boosting, Нейронные Сети).
4. **Результаты**: Предсказание загрязнения, направления ветра и других факторов.

## 🌐 Вторая модель: **Прогнозирования дальнейшей ситуации загрязнения воздуха**

Вторая модель создана для прогнозирования изменения уровня загрязнения в будущем.

### Особенности:
- **Тип модели**: Нейронная сеть с использованием временных рядов.
- **Входные данные**: Исторические данные о загрязнении, погодные условия и направление ветра.
- **Выходные данные**: Прогноз загрязнения в ближайшие часы/дни.
- **Используемые технологии**: PyTorch, ReLU-активация, MSE Loss, SGD Optimizer.
- **Результаты**: Потери (Loss) — 120.69. Модель демонстрирует адекватный уровень предсказания, который будет улучшаться с увеличением данных.

## 📊 Выходные данные моделей

## FAM
Этот код решает задачу методом конечных элементов для 3D куба под действием объёмной силы. 
Основные шаги:
Параметры:Задаются размер куба, свойства материала (модуль Юнга, коэффициент Пуассона, плотность), перегрузка и объёмная сила.
Матрица жесткости:Формируется локальная матрица жесткости для 3D элемента.
Глобальная матрица жесткости:Собирается глобальная матрица жесткости для всей системы.Внешние нагрузки:Формируется вектор внешних сил, действующих на куб.
Граничные условия:Закрепляются степени свободы на нижней грани.
Решение системы:Решается система уравнений для нахождения перемещений узлов.Результаты: Выводятся перемещения узлов куба.
